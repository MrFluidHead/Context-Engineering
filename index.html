01 / UNDERSTAND

The prompt is only
part of the picture.

Context engineering is the practice of selecting and organising the information available to a model for a task. That includes the request, relevant knowledge, conversation history and tools.

01

Instructions

Define the task, audience, boundaries and what a useful result looks like.

“Explain this for a first-year student. Flag uncertainty.”
02

Knowledge

Supply relevant sources and examples. Separate evidence from assumptions.

A selected passage, a rubric or a verified policy.
03

Memory

Carry forward useful decisions and preferences. Remove stale or irrelevant history.

An agreed goal and a short record of earlier decisions.
04

Tools

Give access to the capabilities the task needs, with clear limits and permissions.

Document search for evidence; a calculator for arithmetic.

03 / PUT IT INTO PRACTICE
A small loop.
A deliberate habit.
A clearer brief helps. Checking what comes back matters just as much.
01 / SELECT
Start with the real task.
Identify the decision or learning goal. Include the evidence that helps and leave unrelated material out.
02 / STRUCTURE
Make the boundaries clear.
Label sources, distinguish instructions from quoted text, and specify what to do when evidence is missing.
03 / CHECK
Evaluate the result.
Check accuracy, source support and usefulness against the goal. Revise the context and compare again.
How is this different from prompt engineering?+
Prompt engineering focuses on how you phrase instructions. Context engineering also considers which evidence, history and tool results reach the model, and how those inputs change across steps. The practices overlap.
Does adding context guarantee a correct answer?+
No. Sources can be wrong, information can conflict, and models can still make mistakes. Keep source checks and human review in the workflow. Treat retrieved documents as evidence to inspect, not as trusted instructions.
Can I practise this without an API key?+
Yes. This page works without an API key. Use the brief builder to practise selecting useful information, then try the brief in a chat tool or a local model. Avoid sharing confidential information with services you have not assessed.
